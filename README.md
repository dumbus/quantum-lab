# Application for Analyzing Cryptographic Algorithms via Cloud Access to a Stationary Quantum Computer

[![DOI Code](https://zenodo.org/badge/DOI/10.5281/zenodo.22834190.svg)](https://doi.org/10.5281/zenodo.22834190)
[![DOI Publication](https://zenodo.org/badge/DOI/10.5281/zenodo.22834827.svg)](https://doi.org/10.5281/zenodo.22834827)


> This repository contains all the programs produced while completing a bachelor's thesis titled "Development of an Application for Analyzing Cryptographic Algorithms via Cloud Access to a Stationary Quantum Computer".  
> Not all programs were described in the final version of the thesis. Some were used for testing, exploring the principles of quantum computing, and drafting lab assignment variants.

### The repository includes:
- Programs for simulating the operation of a quantum computer (`/simulations`);
- Programs for lab assignments (`/labs`);
- Programs for simulating simple and controlled quantum gates (`/simple-gates`, `/controlled-gates`);
- Programs used to model the modular exponentiation operation (`/modular-exponentiation-variants`)

## Related publication

This repository accompanies the following thesis:

> Degtyarev, M. (2024). *Development of an Application for Analyzing Cryptographic Algorithms via Cloud Connection to a Stationary Quantum Computer* [Thesis]. Zenodo. https://doi.org/10.5281/zenodo.22834827

The thesis analyzes public-key cryptographic algorithms, the principles of quantum computing, and Shor's algorithm, and describes the implementation of an application that performs integer factorization using cloud access to real quantum hardware, a quantum computer simulator, and a set of laboratory works.

# Приложение для анализа криптоалгоритмов с помощью облачного подключения к стационарному квантовому компьютеру

> Репозиторий содержит все программы, полученные в ходе выполнения выпускной квалификационной работы на тему "Разработка приложения для анализа криптоалгоритмов с помощью облачного подключения к стационарному квантовому компьютеру".  
> Не все программы были описаны в конечной версии работы. Часть программ использовалась для тестирования, изучения принципов квантовых вычислений, а также для составления вариантов лабораторных работ.

### Репозиторий включает в себя:
- Программы для симуляции работы квантового компьютера (`/simulations`);
- Программы для выполнения лабораторных работ (`/labs`);
- Программы для симуляции работы простых и контролируемых квантовых гейтов (`/simple-gates`, `/controlled-gates`);
- Программы, которые использовались для моделирования операции квантового возведения в степень (`/modular-exponentiation-variants`)
